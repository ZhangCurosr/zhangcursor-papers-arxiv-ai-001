# A simple adaptive accelerated optimistic dual averaging method for unconstrained convex optimization in p-norm geometry

Bowen Li<sup>∗</sup> Danqing Zhou<sup>∗</sup> Chuan He<sup>∗</sup>

## Abstract

Eficient preconditioning plays an important role in large-scale first-order optimization. In this paper, we propose an adaptive accelerated optimistic dual averaging $\mathrm { ( A ^ { 2 } O D A ) }$ method for unconstrained convex optimization that adopts low-cost preconditioning based on p-norm geometry for $p \in [ 2 , \infty ]$ . The method is line-search-free and employs a new stepsize selection technique based on an aggregated afine lower model. Its update structure is simple and unified across $p \in [ 2 , \infty ]$ , with the case $p > 2$ requiring no more elaborate updates than the Euclidean case p = 2. Under a generalized local smoothness condition, we derive a convergence bound that separates the efects of constant and gap-dependent curvature, with the latter potentially yielding faster-decaying terms. In the special case of local smoothness, this bound recovers a nearly optimal convergence rate.

Keywords: Convex optimization; accelerated first-order methods; adaptive methods; p-norm geometry;   
optimistic dual averaging; generalized local smoothness.

Mathematics Subject Classification: 90C25; 90C30; 90C06; 68Q25.

## 1 Introduction

In this paper, we consider the unconstrained convex optimization problem

$$
\operatorname* { m i n } _ { x \in \mathbb { R } ^ { n } } f ( x ) ,\tag{1}
$$

where $f : \mathbb { R } ^ { n }  \mathbb { R }$ is a continuously diferentiable convex function. We assume that problem (1) has at least one optimal solution. Since the seminal work on accelerated gradient methods [27], the development of fast first-order methods has remained a central focus in the study of smooth convex optimization. In practice, the performance of first-order methods is influenced by many factors, including the acceleration mechanism, the parameter selection, and the underlying geometry. The goal of this paper is to develop an accelerated first-order method in p-norm geometry that adapts its parameters to the optimization trajectory and achieves a unified convergence bound for all $p \in [ 2 , \infty ]$

In recent years, there has been fruitful research on first-order methods for smooth convex optimization [1, 28, 29]. In particular, many recent eforts have focused on parameter selection in first-order methods, which is often guided by estimates of the Lipschitz constant of the objective gradient. Instead of fixing the parameters based on a global Lipschitz constant, adapting them to local curvature typically leads to much faster practical progress. In this direction, there has recently been growing interest in first-order methods that adapt their parameters based on local curvature without requiring costly line searches. The use of local curvature to select stepsizes has a long history, as exemplified by the well-known Barzilai-Borwein (BB) stepsize [2]. However, directly applying the BB stepsize without line searches does not generally yield convergence guarantees for smooth convex problems. Recently, several studies have proposed novel stepsize schemes for line-search-free gradient methods and established provable convergence guarantees for solving problem (1); see, e.g., [17, 24, 36]. In addition, notable adaptive accelerated gradient methods, including AC-FGM [18] and AdaNAG [33], achieve optimal convergence rates for smooth convex optimization without requiring line searches.

Beyond parameter selection, the choice of geometry is another important aspect of first-order method design. For many constrained problems, replacing the Euclidean squared distance with a suitable Bregman divergence in first-order method design allows the resulting updates to reflect the intrinsic geometry of the feasible region. Well-known examples include the Kullback-Leibler divergence on the probability simplex [4] and the Itakura-Saito divergence on the positive orthant [3]. These examples can be unified under the general mirror descent framework [4, 26], whose update takes the form:

$$
x _ { k + 1 } \in \mathop { \mathrm { a r g } } \mathop { \operatorname* { m i n } } _ { x \in X } \left\{ \langle \nabla f ( x _ { k } ) , x - x _ { k } \rangle + \gamma _ { k } D _ { h } ( x , x _ { k } ) \right\} ,
$$

where $\gamma _ { k } > 0 .$ , X denotes the feasible region, and $D _ { h } ( x , y ) : = h ( x ) - h ( y ) - \langle \nabla h ( y ) , x - y \rangle$ is the Bregman divergence generated by h. When $h ( x ) = \| x \| _ { 2 } ^ { 2 } / 2$ , the update reduces to projected gradient descent. More generally, suitable choices of h allow mirror descent to exploit non-Euclidean geometry. Under the relative smoothness condition

$$
D _ { f } ( x , y ) \leq L D _ { h } ( x , y ) \qquad \forall x , y \in \Omega
$$

for some $L > 0$ , convergence bounds of mirror descent methods can be established in terms of $D _ { h }$ , where Ω is a suitable convex set containing the iterates and relevant comparison points [4, 20]. Mirror descent and relative smoothness extend gradient descent and Lipschitz smoothness in the Euclidean norm, respectively, to non-Euclidean settings. Nonetheless, extending accelerated gradient methods to non-Euclidean mirror descent is nontrivial. There have been many recent studies on acceleration in mirror descent, including both specific accelerated variants [12, 16, 25] and lower bounds on achievable convergence rates [11]. In addition, adaptive mirror descent methods have also been developed [30].

Another line of research explores first-order methods that directly exploit norm geometry to shape search directions. In particular, replacing the squared Euclidean distance with the squared distance induced by a general norm yields the dual preconditioned gradient update [15]:

$$
x _ { k + 1 } = x _ { k } - { \frac { 1 } { \gamma _ { k } } } J _ { * } { \big ( } \nabla f ( x _ { k } ) { \big ) } \in \underset { x \in \mathbb { R } ^ { n } } { \arg \operatorname* { m i n } } \left\{ \langle \nabla f ( x _ { k } ) , x - x _ { k } \rangle + { \frac { \gamma _ { k } } { 2 } } \| x - x _ { k } \| ^ { 2 } \right\} ,
$$

where $\gamma _ { k } > 0 , \| \cdot \|$ and $\| \cdot \| .$ denote a general norm and its dual, respectively, and $J _ { * } ( g ) \in \partial ( \| \cdot \| _ { * } ^ { 2 } / 2 ) ( g )$ for all $g \in \mathbb { R } ^ { n }$ . For convex problems, this preconditioned method achieves an $\mathcal { O } ( T ^ { - 1 } )$ convergence rate in the objective gap under a Lipschitz gradient condition defined using the general norm and its dual, together with a level-boundedness assumption [15], where $T$ denotes the number of iterations. This bound is analogous to that of classical gradient descent. Moreover, this preconditioned gradient descent has also been analyzed under a dual relative smoothness condition [23]. This condition serves as a dual counterpart to the primal relative smoothness condition used to analyze mirror descent [20]. In addition, accelerated variants of preconditioned gradient descent in general norm geometries have been developed in [6, 8]. In particular, when the primal and dual norms are the $p -$ and q-norms, respectively, with $1 / p + 1 / q = 1$ and $2 \leq p < \infty$ , these methods achieve an $\mathcal { O } ( T ^ { - ( 1 + 2 / p ) } )$ convergence rate in the objective gap, matching the lower bounds up to logarithmic factors [7]. From a technical standpoint, these methods rely on the uniform convexity of the proximal regularizer to control linearization errors in their accelerated updates $[ 6 , 8 ]$ . For the case $p > 2$ , the resulting pth-power proximal terms interact with the quadratic terms arising from Lipschitz smoothness, making parameter selection and the convergence analysis more involved than in the case $p = 2$ (see Remark 1). It is also noteworthy that p-norm geometry has attracted significant recent interest in the design of deep learning optimizers, particularly in the endpoint case $p = \infty$ , which leads to sign-based update directions; see, e.g., [5, 10, 13, 22, 31]. These theoretical advances and growing practical interest motivate the following natural question:

Can we design a line-search-free accelerated first-order method for smooth convex optimization that exploits p-norm geometry for preconditioning throughout the range $p \in [ 2 , \infty ] \vartheta$

This paper provides an afirmative answer to this question. Specifically, our proposed method employs an acceleration mechanism that combines optimistic dual averaging [32] in p-norm geometry with weighted iterate averaging [14]. To adapt the regularization parameters, we aggregate past linearizations into an afine model and use this model to derive a new parameter selection rule that directly controls a Lyapunov potential. This construction difers fundamentally from the parameter selection rules used by existing line-search-free accelerated gradient methods in the case $p = 2 \ [ 1 8 , 3 3 ]$

Moreover, our analysis relies on the relaxed dual-potential expansion inequality in Lemma 1, which avoids the need for a uniform convexity inequality for the proximal regularizer. Consequently, our method directly uses the squared p-norm as the proximal regularizer for $p > 2 ,$ , in contrast to existing accelerated methods that rely on p-uniformly convex regularizers [6, 8] (see Remark 1). On the theoretical side, we establish an accelerated convergence rate for the proposed method under a generalized local smoothness condition (see Assumption 1(b)). This condition incorporates gap-dependent curvature into the local smoothness condition and allows us to distinguish the contributions of the constant and gap-dependent curvature terms to the convergence bound. Our main contributions are summarized below.

• We develop an adaptive accelerated optimistic dual averaging $\mathrm { ( A ^ { 2 } O D A ) }$ method under p-norm geometry for solving problem (1). To the best of our knowledge, this is the first line-search-free first-order method that combines adaptive acceleration with squared p-norm regularization in a unified framework covering all $p \in [ 2 , \infty ]$

• Under the generalized local smoothness condition (Assumption 1(b)), we establish a unified convergence bound for Algorithm 1 across all $p \in [ 2 , \infty ]$ that explicitly separates the contributions of constant and gap-dependent curvature (see Theorem 2). In the special case of local smoothness, this bound recovers a nearly optimal convergence rate (see Section 3.4).

The rest of the paper is organized as follows. In Section 2, we introduce the notation and preliminary results. In Section 3, we present the proposed algorithm and state its convergence guarantees. The proof of our main convergence result is presented in Section 4. Additional lemmas and proofs are deferred to the appendix.

## 3 An adaptive accelerated optimistic dual averaging method

In this section, we propose an adaptive accelerated optimistic dual averaging $\left( \mathrm { A ^ { 2 } O D A } \right)$ method in p-norm geometry for $p \in [ 2 , \infty ]$ and establish its convergence properties under the generalized local smoothness condition stated in Assumption 1(b). Specifically, we first describe the main components of the method in Sections 3.1-3.3 and then present the complete algorithm and its convergence results in Section 3.4.

Before proceeding, we let $\left\{ \lambda _ { k } \right\}$ be the positive weights for averaging iterates and gradients, and define the cumulative weights by $\begin{array} { r } { A _ { k } = \sum _ { i = 1 } ^ { k } \lambda _ { i } } \end{array}$ for all $k \geq 1$ . The $\mathrm { A ^ { 2 } O D A }$ method generates two sequences: the optimistic dual-averaging iterates $\left\{ y _ { k } \right\}$ and the weighted-average iterates $\{ x _ { k } \}$ . For convenience, we denote the sequences of function values and gradients evaluated at $\{ x _ { k } \}$ by $\{ f _ { k } \}$ and $\left\{ g _ { k } \right\}$ , respectively, where $f _ { k } = f ( x _ { k } )$ and $g _ { k } = \nabla f ( x _ { k } )$ for all $k \geq 1$

## 3.1 Optimistic dual averaging and acceleration

The proposed method combines optimistic dual averaging with weighted primal averaging to achieve acceleration. It mainly consists of three parts: dual averaging to accumulate past gradients, optimism to predict the next gradient contribution, and weighted primal averaging to construct the iterates at which gradients are evaluated.

Following the dual-averaging strategy [35], we maintain the weighted gradient sum

$$
s _ { 0 } = 0 , \qquad s _ { k } = \sum _ { i = 1 } ^ { k } \lambda _ { i } g _ { i } , \qquad \forall k \ge 1 .
$$

At the beginning of iteration $k ,$ , the new gradient $g _ { k }$ is not yet available. We therefore use the most recent gradient $g _ { k - 1 }$ to predict the contribution of $g _ { k }$ to $s _ { k }$ , forming

$$
\tilde { s } _ { k } = s _ { k - 1 } + \lambda _ { k } g _ { k - 1 } \qquad \forall k \geq 1 .
$$

The term $\lambda _ { k } g _ { k - 1 }$ constitutes the optimistic part: it adds a prediction of the next weighted gradient before that gradient is observed, as in optimistic follow-the-regularized-leader methods [32].

The optimistic dual-averaging iterate $y _ { k }$ is then obtained by minimizing the sum of the predicted linear model and a regularization term:

$$
y _ { k } \in \underset { y \in \mathbb { R } ^ { n } } { \arg \operatorname* { m i n } } \left. \langle \tilde { s } _ { k } , y - x _ { 0 } \rangle + \frac { \gamma _ { k } } { 2 } \| y - x _ { 0 } \| _ { p } ^ { 2 } \right. ,
$$

where $\gamma _ { k } > 0$ controls the regularization strength. Our novel adaptive strategy for updating $\gamma _ { k }$ will be introduced later.

To achieve acceleration, a key ingredient is the coupling of optimistic updates with gradient evaluations at running weighted averages [14]. Specifically, we form the weighted primal average

$$
x _ { k } = \frac { A _ { k - 1 } } { A _ { k } } x _ { k - 1 } + \frac { \lambda _ { k } } { A _ { k } } y _ { k } = \frac { 1 } { A _ { k } } \sum _ { i = 1 } ^ { k } \lambda _ { i } y _ { i } ,
$$

and evaluate the new gradient at the averaged iterate $x _ { k } .$ , rather than at $y _ { k }$ , setting $g _ { k } = \nabla f ( x _ { k } )$

## 3.2 Aggregated afine lower model for adaptive regularization

We now motivate our adaptive strategy for updating the regularization parameters based on an accumulated afine lower model. Following the estimate-sequence and approximate-duality-gap techniques [9, 34], we aggregate supporting afine functions and add a regularization term.

For any $x \in \mathbb { R } ^ { n }$ , we define the aggregated afine lower model $\varphi _ { k }$ by

$$
\begin{array} { l } { \displaystyle \varphi _ { k } ( x ) : = c _ { k } + \langle s _ { k } , x - x _ { 0 } \rangle = \displaystyle \sum _ { i = 1 } ^ { k } \lambda _ { i } ( f _ { i } + \langle g _ { i } , x - x _ { i } \rangle ) \le A _ { k } f ( x ) } \\ { \mathrm { w i t h } \quad c _ { k } : = \displaystyle \sum _ { i = 1 } ^ { k } \lambda _ { i } ( f _ { i } + \langle g _ { i } , x _ { 0 } - x _ { i } \rangle ) , } \end{array}\tag{11}
$$

where the inequality is due to the convexity of $f$ . This model collects the first-order information obtained along the optimization trajectory. It requires only the vector $s _ { k }$ and the scalar $c _ { k }$ , both of which can be updated recursively.

Directly minimizing $\varphi _ { k }$ over $\mathbb { R } ^ { n }$ does not generally yield a useful comparison value. We therefore define the regularized estimating function for any $\gamma > 0$ and its minimum value by

$$
\psi _ { k } ( x ; \gamma ) : = \varphi _ { k } ( x ) + \frac { \gamma } { 2 } \| x - x _ { 0 } \| _ { p } ^ { 2 } , \qquad m _ { k } ( \gamma ) : = \operatorname* { m i n } _ { x \in \mathbb { R } ^ { n } } \psi _ { k } ( x ; \gamma ) = c _ { k } - \frac { \| s _ { k } \| _ { q } ^ { 2 } } { 2 \gamma } ,\tag{12}
$$

where the last equality follows from Fenchel conjugacy. For any minimizer $x _ { * }$ of $f , ( 1 1 )$ then implies

$$
m _ { k } ( \gamma ) \leq \psi _ { k } ( x _ { * } ; \gamma ) \leq A _ { k } f _ { * } + \frac { \gamma } { 2 } \| x _ { * } - x _ { 0 } \| _ { p } ^ { 2 } .\tag{13}
$$

Although $m _ { k } ( \gamma )$ is not necessarily a lower bound on $A _ { k } f _ { * }$ , this inequality provides the comparison needed to control the objective gap.

Motivated by (13), we seek a regularization parameter satisfying

$$
A _ { k } f _ { k } \le m _ { k } ( \gamma ) + \rho _ { k } ^ { 2 } \gamma ,\tag{14}
$$

where $\rho _ { k } > 0$ is a scale to be specified later. The additional term $\rho _ { k } ^ { 2 } \gamma$ is chosen to scale linearly with $\gamma ,$ , matching the regularization term in (13). The condition (14) is computable without knowing $f _ { * }$ Combining it with (13) yields

$$
f _ { k } - f _ { * } \leq \frac { \gamma } { A _ { k } } \Big ( \rho _ { k } ^ { 2 } + \frac 1 2 \| x _ { * } - x _ { 0 } \| _ { p } ^ { 2 } \Big ) .\tag{15}
$$

For a fixed $\rho _ { k }$ , the resulting bound is proportional to $\gamma .$

Given $\gamma _ { k } > 0$ and a safeguard parameter $\theta \in ( 0 , 1 )$ , we select the smallest $\gamma \geq \theta \gamma _ { k }$ satisfying (14):

$$
\gamma _ { k + 1 } : = \operatorname* { m i n } \left\{ \gamma \geq \theta \gamma _ { k } : A _ { k } f _ { k } \leq m _ { k } ( \gamma ) + \rho _ { k } ^ { 2 } \gamma \right\} .\tag{16}
$$

The safeguard limits the decrease in the regularization parameter, while the estimating-function comparison (14) determines whether a value larger than $\theta \gamma _ { k }$ is needed. Denote $\chi _ { k } : = A _ { k } f _ { k } - c _ { k }$ . Using the expression for $m _ { k } ( \gamma )$ in (12), we can rewrite the update (16) explicitly as

$$
\gamma _ { k + 1 } = \operatorname* { m a x } \left\{ \theta \gamma _ { k } , \frac { \chi _ { k } + \sqrt { \chi _ { k } ^ { 2 } + 2 \rho _ { k } ^ { 2 } \| s _ { k } \| _ { q } ^ { 2 } } } { 2 \rho _ { k } ^ { 2 } } \right\} .
$$

Since (14) holds with $\gamma = \gamma _ { k + 1 }$ , it follows from (15) that

$$
f _ { k } - f _ { * } \leq \frac { \gamma _ { k + 1 } } { A _ { k } } \Big ( \rho _ { k } ^ { 2 } + \frac 1 2 \| x _ { * } - x _ { 0 } \| _ { p } ^ { 2 } \Big ) .
$$

## 3.3 Bounded Lyapunov-potential certificate

We now use the estimating-function comparison in Section 3.2 to construct a natural potential sequence $\{ \mathcal { P } _ { k } \}$ for the convergence analysis. Specifically, for all $k \geq 1$ , define

$$
\mathcal { P } _ { k } : = A _ { k } f _ { k } - m _ { k } ( \gamma _ { k + 1 } ) = \chi _ { k } + \frac { \| s _ { k } \| _ { q } ^ { 2 } } { 2 \gamma _ { k + 1 } } ,
$$

where the last equality follows from the definition of $\chi _ { k }$ and (12). The connection between this potential and the objective gap follows from (13), which gives

$$
\mathcal { P } _ { k } \geq A _ { k } ( f _ { k } - f _ { * } ) - \frac { \gamma _ { k + 1 } } { 2 } \| x _ { * } - x _ { 0 } \| _ { p } ^ { 2 } .
$$

Thus, controlling $\mathcal { P } _ { k }$ relative to $\gamma _ { k + 1 }$ provides a bound on the objective gap. In addition, the condition (14), with $\gamma = \gamma _ { k + 1 }$ , ensures that

$$

## 3.4 The $\mathbf { A } ^ { 2 } \mathbf { O D A }$ method and its convergence rate

We now summarize the $\mathrm { A ^ { 2 } O D A }$ method in Algorithm 1, which combines the updates described above.

Algorithm 1 $\mathrm { A ^ { 2 } O D A } ;$ : An Adaptive Accelerated Optimistic Dual Averaging method

We now make a few remarks about Algorithm 1.   
• The parameter $m \geq 2$ controls the growth of the averaging weights: for fixed m, $\lambda _ { k } = \Theta ( k ^ { m - 1 } )$ and   
$A _ { k } = \Theta ( k ^ { m } )$ . In particular, $m = 2$ gives $\lambda _ { k } = k$ and $A _ { k } = k ( k + 1 ) / 2 .$ recovering the linearly increasing   
weights used in accelerated optimistic dual averaging [14]. Allowing $m > 2$ provides flexibility to exploit   
the diminishing gap-dependent curvature under generalized local smoothness, potentially yielding faster   
decay of the corresponding terms in the convergence bound.   
The benefit of increasing m depends on its interaction with the adaptive regularization. Indeed, when   
the sequence of radius scales $\{ \rho _ { k } \}$ is bounded, the objective-gap bound derived above is governed by   
$\gamma _ { k + 1 } / A _ { k }$ . Thus, faster growth of $A _ { k }$ can translate into faster convergence only if it is not ofset by the   
growth of $\gamma _ { k + 1 }$ . The convergence analysis below quantifies this interaction.   
• The scale $\rho _ { k }$ controls the tolerance in the estimating-function comparison (see (14)) and therefore afects   
the update of the regularization parameter $\gamma _ { k + 1 }$ . We choose   
$\rho _ { k } = \frac { 1 } { \alpha } \operatorname* { m a x } _ { 1 \leq i \leq k } \{ \| y _ { i } - x _ { 0 } \| _ { p } \}$

so that this scale adapts to the observed size of the optimization trajectory, without requiring prior knowledge of the distance from $x _ { 0 }$ to a minimizer.

This choice balances two efects: a larger $\rho _ { k }$ relaxes the estimating-function comparison and may allow a smaller regularization parameter, but it also increases the radius-dependent term in the objective-gap bound. This adaptive update is designed to achieve a favorable dependence on problem constants while using only quantities already available from the iterates. A simpler alternative is to use a fixed scale $\rho _ { k } \equiv \rho > 0$

• The initial regularization parameter $\gamma _ { 1 }$ can be selected through an optional backtracking line search, similar to that in [18]. We present its procedure as follows:

2. Initial trial accepted. Repeatedly test $\gamma / 2$ . If accepted, set $\gamma  \gamma / 2 ;$ otherwise, stop.

Under Assumption 1, the calibrated parameter $\gamma _ { 1 }$ satisfies

A proof of this bound is provided in Appendix C. We conclude this section by presenting the convergence rate of the $\mathrm { A ^ { 2 } O D A }$ method under the generalized local smoothness condition in Assumption 1(b). ## B Generalized local cocoercivity
